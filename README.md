# Conditional Maintenance Mode

[![CI](https://github.com/walidsadfi-evolurise/Evolurise-Conditionnal-Maintenance-Mode/actions/workflows/ci.yml/badge.svg)](https://github.com/walidsadfi-evolurise/Evolurise-Conditionnal-Maintenance-Mode/actions/workflows/ci.yml)

Maintenance mode by user role: pick which roles may still browse the site while everyone else sees your maintenance message. Toggle it from the settings page or from the admin bar.

## Install

Upload the folder to `wp-content/plugins/`, activate, then configure under *Settings → Maintenance Mode*.
